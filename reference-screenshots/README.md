# Historical live-site captures

These JPEGs were captured from the live Glamorgan site on 2026-11-05 at 1440 × 900, 768 × 1024, and 390 × 844 CSS viewports. They are retained only to compare page coverage, source content, and responsive structure. The redesign uses the supplied brand kit and new permanent service imagery. The historical graphics and styling are not part of the active site.

Each of the twelve routes has a desktop, tablet, and mobile full-page capture. Additional homepage stage, navigation, and first-screen captures document live behavior. The historical page had rotating reviews, a changing call-tracking number, scroll animations, and lazy-loaded images, so some source captures show partially faded sections.

The active local pages and their new screenshots are documented in `../CHECKLIST.md` and `../final-screenshots/README.md`.
